man pages for agents

awk

Pattern scanning and text processing language. Extremely powerful for columnar data.

cat

Concatenate and print files. Display file contents to stdout.

cd

Change the current working directory. Shell builtin, not a binary.

chmod

Change file mode (permissions).

chown

Change file owner and group.

cp

Copy files and directories.

curl

Transfer data to/from a server using URLs. The Swiss Army knife of HTTP requests.

cut

Remove sections from each line of files.

df

Report file system disk space usage.

dig

DNS lookup utility. Query DNS servers.

docker

Container platform for building and running applications.

du

Estimate file and directory space usage.

find

Search for files in a directory hierarchy. Extremely powerful.

free

Display amount of free and used memory in the system.

gh

GitHub CLI - work with GitHub from the command line.

git

Distributed version control system. Track changes, collaborate, manage code history.

grep

Search for patterns in files. Essential for finding code, logs, and text.

head

Output the first part of files.

jq

Command-line JSON processor. Essential for API work.

kill

Send signals to processes. Terminate or control processes.

less

View file contents with pagination. Better than more.

ln

Create links between files. Hard links or symbolic (soft) links.

ls

List directory contents. The most basic file exploration command.

make

Build automation tool. Execute tasks defined in Makefile.

mkdir

Create directories.

mv

Move or rename files and directories.

nc

Netcat - networking Swiss Army knife. TCP/UDP connections and listeners.

npm

Node Package Manager. Manage JavaScript packages.

ping

Send ICMP ECHO_REQUEST to network hosts. Test network connectivity.

pip

Python package installer.

ps

Report process status. Show running processes.

rm

Remove files and directories. DANGEROUS - no trash, files are gone forever.

rsync

Fast, versatile file synchronization. Better than scp for large transfers.

scp

Secure copy - transfer files over SSH.

sed

Stream editor for filtering and transforming text.

sort

Sort lines of text files.

ssh

Secure Shell - connect to remote machines securely.

sudo

Execute a command as another user (usually root).

tail

Output the last part of files. Essential for log monitoring.

tar

Archive files. Create, extract, and manipulate tar archives.

top

Display real-time system processes. Interactive process viewer.

touch

Create empty files or update file timestamps.

tr

Translate or delete characters. Works on stdin only.

uniq

Report or filter out repeated lines. INPUT MUST BE SORTED FIRST.

wc

Word, line, character, and byte count.

wget

Download files from the web. Non-interactive network downloader.

xargs

Build and execute commands from standard input.
